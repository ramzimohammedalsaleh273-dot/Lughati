# خارطة تنفيذ لغتي

## النواة المنفذة
- تطبيق سطح مكتب RTL.
- SQLite وSQLAlchemy.
- طفل وتقدم ودروس وكلمات ونتائج اختبارات.
- منهج بمستويات 0–12.
- مراجعة متباعدة وحفظ محلي.
- نسخ احتياطي محلي.
- اختبارات تلقائية وGitHub Actions.

## طبقات المحتوى التالية
- مكتبة صوت أصلية/مرخصة مرتبطة بكل درس.
- فيديوهات أصلية/مرخصة.
- قصص تفاعلية.
- ألعاب متعددة.
- مختبر النطق والتحدث.
- اختبارات الاستماع والقراءة والكتابة والمحادثة.
- حسابات متعددة للأطفال وولي الأمر.
- مزامنة اختيارية عند توفر الإنترنت.
- حزم محتوى قابلة للتحديث دون كسر البيانات.

## قاعدة الجودة
لا تعتبر الشاشة مكتملة إلا إذا كان زرها ينفذ وظيفة حقيقية، ويحفظ البيانات، ويملك اختبارًا مناسبًا.
