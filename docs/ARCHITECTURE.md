# بنية لغتي

التطبيق مقسم إلى طبقات: قاعدة البيانات، النماذج، الخدمات، محرك التعلم والمراجعة، المحتوى، الواجهات، والاختبارات.

## قاعدة التنفيذ
كل تقدم يحفظ محليًا. الإنترنت ليس شرطًا للنواة. الوسائط المحلية توضع في media، والنسخ الاحتياطية في backups.

## الجودة
الواجهات لا تعتبر بديلًا عن منطق التطبيق. كل وظيفة جديدة يجب أن ترتبط ببيانات أو خدمة واختبار مناسب.
