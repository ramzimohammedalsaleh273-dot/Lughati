# الدفعة الأولى — لغتي

هذه الدفعة تمثل طبقة المنتج التعليمية الأساسية وليست مجرد واجهات.

## ما تم تنفيذه
- أكاديمية عربية وأكاديمية إنجليزية.
- 13 مستوى لكل لغة.
- ست مهارات أساسية: الاستماع، التحدث، القراءة، الكتابة، المفردات، القواعد.
- محتوى مولد داخل قاعدة البيانات: دروس وأنشطة ومفردات وقصص وأسئلة لكل مستوى.
- ثلاثة أنشطة مرتبطة بكل درس: تهيئة، تطبيق، مراجعة.
- ستة أنواع تقويم: اختيار من متعدد، كتابة، استماع، صح/خطأ، تحدث، مع دعم الترتيب في المحرك.
- محرك إتقان للمستويات وحالة الانتقال للمستوى التالي.
- خطة يومية محفوظة في قاعدة البيانات.
- مراجعة متباعدة للمفردات.
- ألعاب معنى وعكس المعنى والإملاء وصح/خطأ.
- تسجيل صوتي محلي ومكتبة للتسجيلات.
- مكتبة وسائط محلية مع استيراد ملفات مرخصة.
- ملفات متعددة للأطفال واختيار الطفل الحالي.
- لوحة ولي الأمر وحمايتها برمز محلي.
- تقارير وتصدير.
- نسخ احتياطي واستعادة.
- تصدير واستيراد حزم محتوى دون اتصال مع منع التكرار.
- قاعدة بيانات SQLite تعمل دون اتصال، مع WAL وForeign Keys وترقية للمخطط.
- اختبارات آلية وCI تعمل بنجاح بعد إصلاح بيئة Qt والصوت.

## حدود هذه الدفعة
هذه الدفعة لا تعني أن المنتج النهائي 100%. المكونات التي تعتمد على خدمات أو نماذج خارجية، مثل التعرف الآلي المتقدم على الكلام، المساعد التوليدي الكامل، المزامنة السحابية الفعلية، ونظام تحديث خادم الإنتاج، تحتاج تنفيذ الدفعة التالية.
