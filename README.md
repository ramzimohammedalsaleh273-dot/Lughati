# لغتي — مدرسة اللغات

مشروع **لغتي** أصبح متعدد الواجهات:
- **الجوال:** Flutter داخل `mobile/` لاستهداف Android وiOS بواجهة تطبيق حقيقية.
- **سطح المكتب:** Python/PySide6 للنسخة المكتبية الحالية.
- **البيانات:** SQLite محلي وOffline-first.
- **التعلم:** العربية والإنجليزية، 13 مستوى، 6 مهارات، مراجعة وتقدم.
- **الوسائط:** لا تُسجل ملفات وهمية على أنها فيديو؛ الفيديوهات الفعلية يجب أن تكون أصلية أو مرخصة.
- **CI:** يتم فحص Python وFlutter تلقائياً.

## تشغيل الجوال
من داخل مجلد `mobile`:
```powershell
flutter pub get
flutter create .
flutter test
flutter run
```

## بناء Android
```powershell
flutter build apk --release
```

أو:
```powershell
flutter build appbundle --release
```

## بناء iOS
يتطلب جهاز macOS مع Xcode:
```bash
flutter build ios --release
```

## مبدأ مهم
المشروع لا يعتبر الوسائط أو المحتوى الاحترافي مكتملين لمجرد وجود واجهة لها. الفيديوهات التعليمية ذات الشخصيات والأصوات البشرية تحتاج ملفات إنتاج حقيقية أو تراخيص حقيقية، والتحليل الصوتي المتقدم يحتاج نموذجاً صوتياً متخصصاً.
