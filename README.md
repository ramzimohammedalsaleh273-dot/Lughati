# لغتي

تطبيق تعليمي عربي/إنجليزي يعمل دون اتصال بالإنترنت، مبني بـ Python وPySide6 وSQLite/SQLAlchemy.

## التشغيل
- Python 3.12+
- أنشئ بيئة افتراضية ثم ثبّت المتطلبات من requirements.txt
- شغّل: python main.py

## المبدأ
التطبيق ليس واجهة تجريبية: كل شاشة رئيسية مرتبطة بخدمات وقاعدة بيانات محلية، مع محتوى ابتدائي قابل للتوسعة.
